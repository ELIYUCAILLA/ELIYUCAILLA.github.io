Tecnologías Utilizadas

Para el desarrollo del sistema se ha utilizado el lenguaje de programación Python, debido a su facilidad de uso y compatibilidad con bibliotecas para interfaces gráficas. Además, se ha empleado el módulo Tkinter para la construcción de la interfaz y PIL (Pillow) para la gestión de imágenes.
